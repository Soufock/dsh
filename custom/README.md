# Soufock extensions

This fork keeps deployment-specific features under `custom/` and leaves upstream implementation files unchanged. [Administrator login](admin-auth/README.md) adds password login to the standard Web profile while retaining upstream token login.

此 fork 将自定义功能集中在 `custom/`，不修改上游实现文件。[管理员登录说明](admin-auth/README.zh.md)包含安装、密码设置和同步上游的方法。
